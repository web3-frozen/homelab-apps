# Secret sync audit

`PushSecret` seeds durable credentials that previously existed only in Pulumi or
were created by hand. It deliberately uses:

- `updatePolicy: IfNotExists` so an existing value in Infisical is never replaced;
- `deletionPolicy: None` so deleting this GitOps resource never deletes the
  Infisical entry.

The secrets currently pushed are:

| Namespace / Secret | Infisical keys |
|---|---|
| `cloudflare/cloudflare-tunnel-token` | `INFRA_CLOUDFLARE_TUNNEL_TOKEN` |
| `actions-runner-system/controller-manager` | `INFRA_ARC_GITHUB_TOKEN` |
| `longhorn-system/homelab-offhost-s3` | `INFRA_LONGHORN_S3_ACCESS_KEY_ID`, `INFRA_LONGHORN_S3_SECRET_ACCESS_KEY`, `INFRA_LONGHORN_S3_ENDPOINTS`, `INFRA_LONGHORN_S3_CERT` |
| `onchain-monitor/ghcr-pull-secret` | `INFRA_GHCR_DOCKERCONFIGJSON` |
| `argocd/private-runner-repository` | `INFRA_ARGOCD_PRIVATE_RUNNER_DEPLOY_KEY` |
| `demo-app/demo-db-app` | `INFRA_DEMO_DB_PASSWORD` |
| `onchain-monitor/onchain-monitor-db-app` | `INFRA_ONCHAIN_MONITOR_DB_PASSWORD` |

The first five use `updatePolicy: IfNotExists`: they are written once and then
owned by Infisical. The two CloudNativePG app passwords use
`updatePolicy: Replace` because the operator can rotate them; Infisical is kept
as a recoverable backup of the live value.

The following classes are intentionally not pushed:

- Infisical bootstrap material: `infisical-machine-identity`,
  `infisical/infisical-secrets`, PostgreSQL and Redis passwords. Infisical cannot
  be the only recovery source for its own database and encryption keys.
- Helm, cert-manager, Linkerd, Kyverno, Longhorn and webserver TLS secrets, plus
  CNPG CA/TLS material. These are generated by their controllers and are
  recreated from their owning resources. The CNPG *application passwords* are
  pushed above because they protect durable database data.
- Runner JIT tokens, listener configs, Helm release records and Argo CD's
  generated Redis password/admin bootstrap secret. These are ephemeral or
  installation-local state.
- Secrets already sourced from Infisical through an ExternalSecret.
